# Louie Komodo — website

Static site: `index.html`, `works.js` (titles, sizes and room colours for every painting), `parallax.js` (scroll engine), `images/`.

- **Edit a painting's title or size:** `works.js`
- **Preview locally:** open `index.html` in a browser
- **Publish:** commit and push to `main`; GitHub Pages serves the repo root.
